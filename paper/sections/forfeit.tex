forfeit is a property of the smoothing \emph{strength}, not Placement~A, and it buys something:
travel falls from $28{,}311$ to $202$. The forfeit's sign is counter-intuitive, so it is worth

it does instead is delay a correction that has already been computed, so the accumulator excurses
\emph{further} rather than less: smoothing the output does not damp $E_t$ but feeds it.

$\tau \le \mu_t(b/2-|\hat{q}_t|)$. Under saturation the deployed value is pinned $\tau$ below the
integrator's ceiling, and the deployed value's realised supremum is $b-\tau$ to the printed
digit at every $\tau \ge 0.9$. Outside the radius the answer turns on two different levels of the
integrator, and condition~(4) names only one of them. The two are the largest correction $r_t$
ever issues and the correction it is guaranteed to issue once the accumulator has cleared the
radius; where they differ, a boundary written with the first of them over-certifies.
Write $A^{+}_t = \sup_x r_t(x)$ and $A^{-}_t = \inf_x r_t(x)$ for the integrator's extremes, and
$\Lambda^{+}_t = \inf_{x \ge c\,h(t)} r_t(x)$, $\Lambda^{-}_t = \sup_{x \le -c\,h(t)} r_t(x)$ for
the levels it is \emph{guaranteed} to reach once the accumulator clears the radius.
Condition~(4) says exactly $\Lambda^{+}_t \ge b$ and $\Lambda^{-}_t \le -b$; that
$\Lambda^{\pm}_t = A^{\pm}_t$, that the integrator reaches its extremes where~(4) puts them, is a
further hypothesis and not one~(4) supplies. Set
\begin{equation}
  \tau^{\star\pm} \;=\; \sup_t\big(|A^{\pm}_t| \pm \hat{q}_{t+1}\big) - b/2,
  \qquad
  \sigma^{\pm} \;=\; \inf_t\big(|\Lambda^{\pm}_t| \pm \hat{q}_{t+1}\big) - b/2 .
  \label{eq:boundaries}
\end{equation}

\textbf{Failure, over the whole admissible class.} If $\tau > \tau^{\star+}$ then $\hat{q}_{t+1} +
A^{+}_t - \tau < b/2$ at every round, so $\tilde{q}_{t+1} \le \max(\tilde{q}_t, q_{t+1}-\tau)$
makes $\{\tilde{q} < b/2\}$ absorbing: a release upward lands below $b/2$, and a hold or a
release downward cannot lift the deployed value at all. Against $s_t =
\mathrm{clip}(\tilde{q}_t+\varepsilon,\pm b/2)$ the indicator is then $\mathbf{1}\{\tilde{q}_t <
b/2\}$ and every round misses. If $\tau \ge \tau^{\star-}$ the constant legal play $s_t \equiv
-b/2$ makes $\{\tilde{q} \ge -b/2\}$ absorbing by the mirror inequality, so no round can miss and
the realised rate is $0$ rather than $\alpha$.
Either way long-run coverage is lost, with $|E_T|$ linear in $T$. Nothing
here asks $\hat{q}$ to be constant, asks the extremes to be attained anywhere, or asks $A^{\pm}_t$
to be finite beyond what the hypothesis already forces. \textbf{Retention, keyed to the reach
rather than the supremum.} If $\tau \le \sigma^{+}$ then $E_{t-1} \ge c\,h(t-1)$ forces $q_t \ge
b/2+\tau$ and so $\tilde{q}_t \ge b/2$, whence $\mathrm{err}_t = 0$ against \emph{every} legal
adversary; if $\tau < \sigma^{-}$ the mirror forces $\mathrm{err}_t = 1$ below $-c\,h(t-1)$. The
accumulator cannot then leave $[-c\,h(t),c\,h(t)]$ by more than one round, and $|E_T| \le
c\,h(T)+1$: Proposition~2's own bound, retained verbatim rather than weakened to $o(T)$. Using
condition~(4) alone this already certifies $\tau \le b/2+\inf_t\hat{q}_t$ and $\tau < b/2 -
\sup_t\hat{q}_t$, which for a constant scorecaster is Corollary~2's radius at $\mu_t = 1$.

\paragraph{The two directions meet, with no gap, on the sub-class the five settings inhabit.} If
$\hat{q}_t \equiv \hat{q}$, if $\Lambda^{\pm}_t = A^{\pm}_t$, and if neither depends on $t$, then
$\sigma^{\pm} = \tau^{\star\pm}$ and \textbf{coverage is retained against every legal adapted
adversary if and only if $\tau \le \tau^{\star+}$ and $\tau < \tau^{\star-}$.} For a symmetric
saturator that is one line: coverage if and only if $\tau \le \sup_x r_t(x) - b/2 - |\hat{q}|$,
with the endpoint included only when $\hat{q} < 0$. Every setting run here is in that sub-class,
so the sharp form applies to all five. \textbf{What was printed before is the failure half.}
